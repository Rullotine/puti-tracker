Drop your own ambient audio files in this folder (mp3, ogg, wav, m4a, aac, flac, webm).

- Every file becomes its own sound, in BOTH the Focus tab and the Groups tab.
  The name comes from the file name: "heavy-rain.mp3" -> "Heavy rain", "Lo_fi beats.ogg" -> "Lo fi beats".
- If a file is named after a built-in sound (rain, waves, wind, lofi, campfire, cafe, forest,
  vinyl, pink, brown, storm, night, fan, train) it REPLACES that built-in synth.
- Use files that loop cleanly (30s+ works well). Keep each one a few MB at most so the site stays fast.
- Friends in a group can only hear a file-based sound if their copy of the site has the same file,
  so keep the folder in sync (it is part of the site's source code).
