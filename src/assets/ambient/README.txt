Drop real ambient audio files here. The file name (without extension) must match the sound id:

  pink  brown  rain  waves  wind  lofi  campfire  cafe  forest  vinyl

Examples: rain.mp3, campfire.ogg, cafe.wav
Supported: mp3, ogg, wav, m4a, aac, flac, webm.
Any sound with a file here plays the file (looped); the others use the built-in synth.
Use files that loop cleanly (30s+ works well).
